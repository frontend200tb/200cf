ДП 7. На подотрезках

Чаще всего в задаче есть n элементов a1, a2, ..., an. Задается вопрос: найдите какую-то величину на всем массиве. Для решения нужна дополнительная память, создадим матрицу Dp размером n x n. В каждой ячейке будем хранить промежуточный ответ. В Dp[l][r] храним ответ для отрезка [l, r]. Смысл в том, что сразу ответить на размере от 1 до n тяжело, поэтому собирать ответ будем по кусочкам.

Основная идея в том, что у нас уже есть отрезок [l1, r1] на котором уже посчитали ответ. Мы добавляем один элемент справа и считаем ответ на отрезке [l1, r1+1].

Как будет заполняться матрица? Мы всегда поддерживаем условие, что левая граница меньше или равна правой границе l <= r. Поэтому матрица будем иметь треугольный вид с вершинами в клетках [1,1], [1,n], [n,n]. Ответ на задачу чаще всего находится в ячейке Dp[1][n].

Поскольку для решения мы пользуемся дополнительной матрицей, то число элементов должно быть не большим, n <= 10³.

Задача 1. Палиндром

Дана строка s. Надо найти палиндром максимальной длины. Символы для палиндрома можно брать из строки не подряд, а пропуская ненужные символы. Полученный палиндром должен читаться слева направо и справа налево одинаково.

Разберем задачу на примере s = abca. Каждый символ строки сам по себе является палиндромом длины 1.

Создадим матрицу Dp, где Dp[l][r] хранит палиндром максимальной длины от s[l] до s[r]. Базовый случай Dp[i][i] = 1.

Пусть мы знаем ответ для строки от s[l1] до s[r1], то есть известно значение Dp[l1][r1]. Построим ответ для Dp[l1][r1+1]. Рассмотрим 2 варианта.

1. Если s[l1] == s[r1+1], то уменьшим наш отрезок на 1 с каждой стороны и будем искать палиндром на отрезке от s[l1+1] до s[r1]. Но для этого отрезка раньше мы уже нашли ответ, тогда

Dp[l1][r1+1] = 2 + Dp[l1+1][r1]

2. Если s[l1] != s[r1+1], то будем искать максимум из двух палиндромов Dp[l1][r1] и Dp[l1+1][r1+1].

Мы будем заполнять матрицу, используя ячейку слева и ячейку снизу, потому что на них уже подсчитан ответ, ведь базовый случай Dp[i][i] = 1 лежит на главной диагонали. Ответ будет хранится в ячейке Dp[1][n].

Задача 2. Палиндром из подряд идущих элементов

Дана строка s. Найти максимальный палидром из подряд идущих символов.

Требуется найти отрезок l,r который является палиндромом.

Здесь возможны несколько решений.

Первое решение. Наивное решение - цикл в цикле в цикле. Асимптотика n³

for (int l = 1; l <= n; l++) {
  for (int r = 1; r <= n; r++) {
    for (i = l; i <= r; i++) {
      проверка на палиндром
    }
  }
}

Второе решение. Будем брать i, и идти от него влево и вправо, проверяя что символы одинаковые. Это цикл в цикле. Асимптотика n². Потом нужно проверить на четность, то есть взять два одинаковых соседних символа и идти от них влево и вправо.

for (int i = 1; i <= n; i++) {
  for (int j = 1; j <= n; j++) {
    проверка на палиндром
  }
}

Третье решение правильное. ДП на подотрезках. Создадим матрицу Dp, где в ячейке Dp[l][r] хранится 1 если отрезок l,r является палиндромом. Базовый случай это что каждый единичный символ уже является палиндромом длины 1. Тогда мы можем заполнить диагональ матрицы Dp[i][i] = 1.

for (int i = 2; i < n; i++) {
  for (int j = 0; j <= n - i; j++) {
    if (s[j] == s[i + j] && Dp[j+1][j+i-1] == 1) {
      Dp[j][j+i] = 1;
    }
  }
}

Заполняем матрицу. Потом пробегаем по матрице и находим самый длинный палиндром.

Вариант этой задачи. Если нам надо ответить на запрос, сколько палиндромов находится на отрезке l,r. Сначала собираем матницу Dp, потом собираем двумерную префик-сумму.

Задача 3. Получить максимальное выражение

Дана последовательность чисел. Нужно расставить между ними знаки + и * и скобки () так чтобы получилось выражение с максимальным значением.

Например даны числа 1, 2, 3. Если везде поставить знак *, то получим

1 * 2 * 3 = 6

Но правильный ответ будет другой

(1 + 2) * 3 = 9

Создадим матрицу Dp. В ячейке Dp[l][r] храним ответ на отрезке l,r. Базовый случай это когда ответ для одного числа это и есть само число, Dp[i][i] = ai. Поскольку диагональ уже заполнена, то будем искать ответ, зная ответ из ячейки слева и из ячейки снизу.

Dp[l][r] = max(Dp[l][k] + Dp[k+1][r], Dp[l][k] * Dp[k+1][r]);

где k это символ между l и r. Позицию k придется перебирать в цикле от главной диагонили до позиции i.

Ответ на задачу будет в Dp[1][n].

for (int j = 0; j < n; j++) {
  for (int i = j - 1; i >= 0; i--) {
    for (int k = j; k < i; k++) {
      Dp[i][j] = max(Dp[i][j], max(Dp[i][k] + Dp[k+1][j],
      Dp[i][k] * Dp[k+1][j]));
    }
  }
}

Задача 4. Порядок важен

Дано n матриц. Определить минимальное количество действий для их перемножения. Необходимо расставить скобки в выражении A1 * A2 * ... * An, чтобы сумма действий была минимальной.

Пример

Даны три матрицы A1[4][3], A2[3][7], A3[7][2]. Нужно перемножить A1 * A2 * A3. При перемножении двух матриц мы перемножаем строки одной матрицы на столбцы другой. Это можно сделать, если перемножаем Ank * Bkm = Cnm

Посчитаем число действий для (A1 * A2) * A3 и для A1 * (A2 * A3)

A1 * A2 = 4 * 3 * 7 = 84 (A1 * A2) * A3 = 4 * 7 * 2 = 56

В результате 84 + 56 = 140 действий нужно чтобы перемножить матрицы способом (A1 * A2) * A3

A2 * A3 = 3 * 7 * 2 = 42 A1 * (A2 * A3) = 4 * 3 * 2 = 24

В результате 42 + 24 = 66 действий нужно чтобы перемножить матрицы способом A1 * (A2 * A3)

Видим, что порядок перемножения важен.

Решим эту задачу. Создадим матрицу Dp. Если есть только одна матрица, то не нужно выполнять никаких действий, это базовый случай. По диагонали заполняем Dp[i][i] нулями.

int n;
cin >> n;

vector > A(n);
for (int i = 0; i < n; i++) {
  cin >> A[i].first >> A[i].second;
}

vector > Dp(n+1, vector (n+1, 1e18));
for (int i = 0; i <= n; i++) {
  Dp[i][i] = 0;
}

for (int r = 1; r < n; r++) {
  for (int l = r-1; l >= 0; l--) {
    for (int k = n-1; k >= l; k--) {
      long long z = A[l].first * A[k+1].first * A[r].second;
      Dp[l][r] = min(Dp[l][r], Dp[l][k] + Dp[k+1][r] + z);
    }
  }
}

cout << Dp[0][n-1] % (1e9+9);
