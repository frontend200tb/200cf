Функция Эйлера

Наибольший общий делитель (НОД) двух чисел a и b это такое максимальное число c, что a делится на c и b делится на c.

Для нахождения НОД применяется алгоритм Евклида. Из большего числа вычитается меньшее пока числа a и b не станут равны.

while (a != b) {
  if (a > b) {
    a = a - b;
  } else {
    b = b - a;
  }
}

Можно найти такие случаи, например при a = 1e9 и b =2, когда алгоритм Евклида по времени не уложится в 1с. Поэтому для нахождения НОД мы модифицируем алгоритм и будем выполнять не вычитание а остаток от деления.

while (a > 0 && b > 0) {
  if (a > b) {
    a = a % b;
  } else {
    b = b % a;
  }
}

В результате пара a, b превратится в пару c, 0. Где c это НОД.

Функция Эйлера Fe(n) = k показывает сколько есть чисел от 1 до n взаимно простых с числом n. Сколько существует чисел от 1 до n которые имеют НОД(i, n) = 1.

Например, числа 6 и 7 взаимно простые.

Свойства функции Эйлера:

  1. Если n - простое число, то k = n - 1
  2. Если n - простое число, a - натуральное число, то Fe(na) = na - na-1
  3. Если a и b взаимно простые, то Fe(a * b) = Fe(a) * Fe(b).

Исходя из этих свойств, можно быстро найти функцию Эйлера для любого числа. Любое число n можно представить как произведение его простых делителей. n = p1a1 * p2a2 * ... * pkak.

int phr(int n) {
  int res = n;

  for (int i = 2; i <= n; i++) {
    if (n % i == 0) {
      while (n % i == 0) {
        n /= i;
      }
      res -= res/i;
    }
  }

  if (n > 1) {
    res -= res/n;
  }

  return res;
}

Из этого следует, что

aFe(m) ≡ 1 (mod m)

где a и m взаимно простые числа. Если число m простое, то

am-1 ≡ 1 (mod m)

Это является малой теоремой Ферма.

Реализация расширенного алгоритма Евклида.

Для двух чисел a и b существует НОД(a,b). Существуют ли такие значения x и y, что

a*x + b*y = НОД(a,b)

Это уравнение прямой на плоскости. Нужно подобрать точку на плоскости, которая будет удовлетворять уравнению прямой и иметь целочисленные координаты.

Упростим коэффициенты уравнения по алгоритму Евклида. a и b станут c и 0.

int gcd(int a, int b, int &x, int &y) {
  if (a == 0) {
    x = 0;
    y = 1;
    return b;
  } else {
    int x1, y1;
    int d = gcd(b % a, a, x1, y1);
    x = y1 - (b/a) * x1;
    y = x1;
    return d;
  }
}

Диафантово уравнение

Решим Диафантово уравнение в целых чилах. Это уравнение прямой.

a*x + b*y = c

Если мы зафиксируем x и найдем из уравнения y. То это нам не подойдет, потому что y будет вещественным числом. А нам нужно чтобы и x и y были целые числа.

Ситуация a = b = 0 это вырожденная ситуация и она уже не является Диафантовым уравнением. При c = 0 имеет бесконечно много решений, или не имеет решений в ином случае.

Диафантово уравнение имеет решение только если c делится на НОД(a,b).

bool Find_any_solution(int a, int b, int c,
  int &x0, int &y0, int &g) {
  g = gcd(abs(a), abs(b), x0, y0);
  if (c % g != 0) {
    return false;
  } else {
    x0 *= c/g;
    y0 *= c/g;
    if (a < 0) {
      x0 *= -1;
    }
    if (b < 0) {
      y0 *= -1;
    }
    return true;
  }
}

Проблема с нахождением остатка от деления у отрицательных чисел. Остаток от деления a % b = k определяется выражением a - c * b + k.

Обратный элемент

При сложении a + b = 0, обратный элемент b = -a.

При умножении a * b = 1, обратный элемент b = a-1.

Как найти обратный элемент для a * b = 1, если мы работаем на кольце по модулю mod m.

Пример. a = 3, b = 3, m = 8

(a * b) % m = 9 % 8 = 1

a * b = 1, значит для a = 3 обратный элемент по модулю 8 равен b = 3.

Воспользуемся функцией Эйлера и малой теоремой Ферма. Пусть

a * b = aFe(m)

Если a и m простые числа, то

aFe(m) = 1

Тогда

b = aFe(m)-1

Теперь нам нужно научиться быстро находить значение выражения aFe(m)-1. Разложим степень на степени двойки. Например, Fe(m)-1 = 100 = 64 + 32 + 4

b = aFe(m)-1 = a100 = a64*a32*a4

Создадим массив Bin_level, где Bin_level[i] = a2i. Тогда

Bin_level[i] = Bin_level[i-1] * Bin_level[i-1];

Чтобы не выйти за пределы типа данных, будем ответ брать по модулю m.

Bin_level[i] = (Bin_level[i-1] * Bin_level[i-1]) % m;

Поиск факториала

Дано число n. Необходимо найти факториал по модулю p. n! % p. Как быстро это сделать?

n! % p = (((1%p)*2%p)*3%p)...

Это очень долго при больших n. Такое выражение нужно сокращать.

Модифицированный НОД

Даны два числа a и b. Приходит q запросов с числами li, ri. Найти максимальное число от l до r, которое является делителем a и b.

long long a, b;
cin >> a >> b;
long long d = gcd(a, b);
int q;
cin >> q;
vector G;

for (long long i = 1; i <= d; i++) {
  if (d % i == 0) {
    G.push_back(i);
    if (d != i * i) {
      G.push_back(d/i);
    }
  }
}

sort (G.begin(), G.end());

for (int h = 0; h < q; h++) {
  cin >> a >> b;
  int l = 0;
  int r = G.size();
  int m;

  // бинарный поиск
  while (r-l>1) {
    m = (l+r)/2;
    if (G[m] > b) {
      r = m;
    } else {
      l = m;
    }
  }
}

if (G[l] >= a) {
  cout << D[l] << '\n';
} else {
  cout << -1 << '\n';
}
