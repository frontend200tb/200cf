Гамильтонов путь и цикл

Гамильтонов путь это способ обойти граф таким образом, что вы пройдете все вершины, посетив каждую ровно один раз.

Гамильтонов цикл это обход графа таким образом, что вы посещаете каждую вершину ровно один раз, кроме начальной и конечной. То есть , начать и закончить нужно в одной и той же вершине.

Эйлеров путь это обход графа, пройдя по каждому ребру ровно один раз.

Эйлеров цикл это усложнение Эйлерова пути, при котором мы должны начать и закончить в одной и той же вершине.

Для нахождения Гамильтонова пути используются перебор и умный перебор. Умный перебор это динамическое программирование по бит маскам.

Для нахождения Эйлерова пути разделим задачу на две части. Сначала проверим существование Эйлерого пути, потом найдем его.

Для существования Эйлерова цикла должно выполняться 2 условия

  1. Степень каждой вершины должна быть четной.
  2. Граф должен быть связный. Все ребра должны находиться в одной компоненте связности. Изолированные вершины в таком случае допускают существование Эйлерова цикла.

Для существования Эйлерова пути должно выполняться 2 условия:

  1. Степень каждой вершины должна быть четной, кроме двух вершин. Две вершины обязательно должны имет нечетную степень. Именно эти вершины являются началом и концом пути.
  2. Граф должен быть связный. Все ребра должны находиться в одной компоненте связности. Изолированные вершины в таком случае допускают существование Эйлерова цикла.

Проверим существования Эйлерова пути. Создадим дополнительный вектор vector<int> Level(n+1). При считывании каждого ребра (a,b) увеличиваем на 1 степень вершины a и степень вершины b. Затем запускаем алгоритм bfs или dfs для обхода графа и проверяем, что мы посетили все вершины. Это означает что все вершины находятся в одной компоненте связности.

Студенческая (оптимальная) реализация может быть решена при n ≤ 105 m ≤ 105

Для нахождения Эйлерова цикла можно начинать с любой вершины.

Достаточно чтобы граф состоял из простейших циклов. Наша задача вытащить все эти циклы.

Для удаления графа создадим дополнительный трехмерный вектор vector<vector<vector<int> > > Cycle. i отвечает за номер вершины, j отвечает за номер цикла, k отвечает за сам цикл.

Рассмотрим пример. Нам задан граф своими ребрами

(1,2),(2,3),(1,4),(3,4),(4,5),(3,5),(3,6),(5,6),(5,7),(4,8),(7,8).

Если граф является Эйлеровым циклом, то после удаления всех циклах, граф полностью удалится. Если граф является Эйлеровым путем, то после удаления всех циклов, останется одно ребро, соединяющее вершину старт и вершину финиш.

Соберем из списка ребер список смежности

1: 2 4
2: 1 3
3: 2 4 5 6
4: 1 3 5 8
5: 3 4 6 7
6: 3 5
7: 5 8
8: 4 7

Мы видим, что у каждой вершины степень четная.

Создадим стек stack<int> st. Обойдем граф и найдем все циклы.

Начиная с любой вершины (мы начнем с 1) будем добавлять вершины, соединенные ребрами, в стек, пока не найдем цикл.

st = {1, 4, 8, 7, 5, 3, 4}

Мы видим, что вершина 4 встретилась 2 раза. Теперь удаляем эти вершины из стека и удаляем соответствующие ребра из списка смежности. Получим стек

st = {1, 4}

Получим список смежности

2: 1 3
3: 2 6
4: 1 5
5: 4 6
6: 3 5

Так мы найдем и уничтожим все циклы, которые видны из стартовой вершины, но не все циклы.

void dfs(vector<vector<int> > &G,
  vector<int> &Mark,
  vector<vector<vector<int> > > &Cycle,
  stack<int> st,
  int x,
  int y) {

  Mark[x] = 1;
  st.push(x);
  for(int i = 0; i < G[x].size(); i++) {
    if (G[x][i] != y && G[x][i] != 0) {
      if (Mark[G[x][i]] == 0) {
        dfs(G, Mark, Cysle, st, G[x][i], x);
      } else {
        delete_cycle(G, Mark, Cycly, st, G[x][i], x);
      }
    }
  }
}

void delete_cycle(vector<vector<int> > &G,
  vector<int> &Mark,
  vector<vector<vector<int> > > &Cycle,
  stack<int> st,
  int x,
  int y) {

  st.push(x);
  int a, b;
  a = st.top();
  st.pop();
  b = st.top();
  st.pop();
  vector<int> tmp;
  Cycle[x].push_back(tmp);

  // удаляем цикл
  while (b != x) {
    Cycle[x][Cycle[x].size()-1].push_back(b);

    // сначала ищем первую вершину ребра и удаляем ее
    for (int i = 0; G[a].size(); i++) {
      if (G[a][i] == b) {
        G[a][i] = 0;
      }
    }

    // потом ищем вторую вершину ребра и удаляем ее
    for (int i = 0; G[b].size(); i++) {
      if (G[b][i] == a) {
        G[b][i] = 0;
      }
    }

    // смещаем стек
    a = b;
    b = st.top();
    st.pop();
    Mark[b] = 0;
  }

  // восстановим последний удаленный элемент в стеке
  Mark[x] = 1;
  st.push_back(x);
}
