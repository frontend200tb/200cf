Задача

ДП 5. Наибольшая возрастающая подпоследовательность

Пусть дан массив элементов, тогда

Последовательность - это подряд идущие элементы массива.

Подпоследовательность это не подряд идущие элементы массива, которые можно вынести в новый массив, не меняя порядка элементов.

Возрастающая подпоследовательность это когда каждый следующий элемент строго больше чем предыдущий.

Наибольшая возрастающая подпоследовательность это возрастающая подпоследовательность максимальной длины.

Пример, дан массив

1 3 5 3 4 6 2 1

Видно, что НВП это

1 3 4 6

Для НВП рассмотрим два варианта реализации: школьный и студенческий. Сложность школьного варианта O(n2). Сложность студенческого варианта O(n log n).

Школьный НВП

Создадим вспомогательный вектор, изначально содержащий единицы

vector<int> Len(n, 1);

Почему 1? Даже если он будет содержать всего один элемент, это будет считаться возрастающей подпоследовательностью.

Будем постепенно строить возрастающую подпоследовательность, начиная с 1 элемента по i-й элемент. Будем считать, все что левее i-го элемента уже построено.

Если A[j] < A[i], то существовала НВП, заканчивающаяся на j элемент и к ней еще можно добавить элемент A[i]. Значит к длине подпоследовательности, которая заканчивалась на j-й элемент, мы можем добавить еще один элемент A[i] и длина увеличится.

Перебор всех вариантов позволяет найти наилучший вариант.

vector<int> Len(n, 1);

for (int i = 0; i < n; i++) {
  for (int j = 0; j < i; j++) {
    if (A[j] < A[i]) {
      Len[i] = max(Len[i], Len[j] + 1);
    }
  }
}

Студенческий НВП

В школьнов варианте улучшим поиск продолжения цикла.

Рассмотрим две версии реализации: через вектор и через мультисет.

Создадим вспомогательный вектор, изначально содержащий значения 1e9.

vector<int> Len(n, 1e9);

В Len[i] будем хранить элемент, на который заканчивается НВП длины i. Почему 1e9? Потому что это недостижимый элемент.

vector<int> Len(n+1, 1e9);
Len[0] = 0;

for (int i = 0; i < n; i++) {
  int l = 0;
  int r = n;
  int mid;

  while (r-l > 1) {
    mid = (l+r) / 2;
    if (Len[mid] >= A[i]) {
      r = mid;
    } else {
      l = mid;
    }
  }

  if (Len[l] >= A[i]) {
    Len[l] = A[i];
  } else {
    Len[r] = A[i];
  }
}

Вторая версия реализации. Вместо вектора создадим мультисет. В мультисет запишем значение 1e9. В мультисете будем искать lower_bound(A[i]), его удалять и вместо него вносить A[i].

Задача

Даны n конвертов и открытка размером w на h. Нужно собрать максимальное количество конвертов, которые можно сложить один в другой и в самый внутренний положить открытку.

int n; // число конвертов
int w; // ширина открытки
int h; // высота открытки
cin >> n >> w >> h;

pair<pair<int, int>, int> > t;
vector<pair<pair<int, int>, int> > A;

for (int i = 0; i < n; i++) {
  t.second = i + 1;
  cin >> t.first.first >> t.first.second;
  if (t.first.first > w && t.first.second > h) {
    A.push_back(t);
  }
}

sort(A.begin(), A.end());
vector<int> Put(n+1, -1);
vector<int> DP(n+1, 1);

for (int i = 0; i < A.size(); i++) {
  for (int j = 0; j < i; j++) {
    if (A[i].first.first > A[j].first.first
    && A[i].first.second > A[j].first.second) {
      if (DP[i] < DP[j] + 1) {
        DP[i] = DP[j] + 1;
        Put[i] = j;
      }
    }
  }
}

int uk = -1;
int len = 0;

for (int i = 0; i < A.size(); i++) {
  if (len < DP[i]) {
    len = DP[i];
    uk = i;
  }
}

stack<int> st;

while (uk != 0) {
  st.push(A[uk].second);
  uk = Put[uk];
}

cout << len << '\n';
while (st.size() > 0) {
  cout << st.top() << ' ';
  st.pop();
}
