Задано целое положительное число n. Выведите его запись в двоичной системе счисления.

Входные данные

В единственной строке входных данных записано целое число n (1 ≤ n ≤ 10⁶).

Выходные данные

Выведите запись числа n в двоичной системе счисления (без ведущих нулей).

Примеры

Пример 1

5

101

Пример 2

13

1101

В первом примере 5 = 1 * 2² + 0 * 2¹ + 1 * 2⁰.
