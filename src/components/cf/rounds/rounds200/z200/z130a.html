Шестиугольные числа — фигурные числа, которые можно вычислить по следующей формуле: hn = 2n² - n. Вам дан номер n; вычислите n-ое шестиугольное число.

Входные данные

Единственная строка входных данных содержит целое число n (1 ≤ n ≤ 100).

Выходные данные

Выведите n-ое шестиугольное число.

Примеры

Пример 1

2

6

Пример 2

5

45
