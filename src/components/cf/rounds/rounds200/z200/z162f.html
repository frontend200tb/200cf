Вам дано целое положительное число n. Выведите количество нулей, которыми оканчивается n! (n! означает произведение чисел от 1 до n, включительно).

Входные данные

Единственная строка входных данных содержит целое число n (1 ≤ n ≤ 1000000).

Выходные данные

Выведите количество нулей, которыми оканчивается n!.

Примеры

Пример 1

6

1

Пример 2

24

4

В первом примере 6! = 720.

Во втором примере 24! = 620448401733239439360000.
