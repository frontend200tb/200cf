(Время 2с. Память 64мб)

Вам дано число n. Выведите его разложение на простые множители.

Если n = a1b1a2b2 ... akbk, где ak — простые числа, то вывод программы должен выглядеть следующим образом: a1 a1 ... a1 a2 a2 ... a2 ... ak ak ... ak, где множители упорядочены в порядке неубывания, и каждый множитель ai указан bi раз.

Входные данные

Единственная строка входных данных содержит целое число n (2 ≤ n ≤ 250).

Выходные данные

Выведите разложение числа n на простые множители в формате, описанном выше.

Примеры

Пример 1

245

5 7 7

Пример 2

13

13
