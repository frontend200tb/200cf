Числа трибоначчи — последовательность, заданная рекуррентным соотношением:

t0 = t1 = 0, t2 = 1, ti = ti - 1 + ti - 2 + ti - 3.

Вам дан номер n; вычислите n-ое число трибоначчи по модулю 26.

Входные данные

Единственная строка входных данных содержит целое число n (1 ≤ n ≤ 1000).

Выходные данные

Выведите n-ое число трибоначчи по модулю 26.

Примеры

Пример 1

4

2

Пример 2

9

18
