(Время 3с. Память 256мб)

Вам дан массив целых чисел, записанных в системе счисления с основанием radix. Вычислите их сумму и выведите ее в той же системе счисления.

Входные данные

В первой строке записано целое число n (1 ≤ n ≤ 10) — размер массива. Во второй строке записано целое число radix (2 ≤ radix ≤ 36) — основание использующейся системы счисления. Следующие n строк содержат элементы массива, по одному на строку.

Каждый элемент массива является неотрицательным числом, записанным в системе счисления с основанием radix, возможно, с лидирующими нулями, и содержит от 1 до 5 цифр, включительно. В качестве "цифр" системы счисления используются символы 0, 1, ..., 9, A, B, ..., Z в указанном порядке.

Выходные данные

Выведите сумму чисел массива в системе счисления radix. Используйте тот же формат записи, что и для ввода чисел.

Примеры

Пример 1

3
16
F0
20B
004

2FF

Пример 2

2
10
12
34

46
