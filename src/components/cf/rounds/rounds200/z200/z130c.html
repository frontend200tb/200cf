Вам дан массив целых чисел. Посчитайте сумму всех чисел в нем.

Входные данные

В первой строке записано целое число n (1 ≤ n ≤ 100) — размер массива. Следующие n строк содержат элементы массива, по одному на строку. Все элементы массива — целые числа от 1 до 100, включительно.

Выходные данные

Выведите сумму элементов массива.

15
