(Время 1с. Память 64мб)

Маленький Петя очень любит играть. Больше всего он любит играть в игру «Лунки». Это игра для одного игрока со следующими правилами:

Есть N лунок, расположенных в ряд, пронумерованных слева направо числами от 1 до N. У каждой лунки изначально установлена своя сила выброса (у лунки с номером i она равна ai). Если вбросить шарик в лунку i, то он тут же вылетит из нее и попадет в лунку i + ai, после чего он опять вылетит и т.д.. Если же лунки с таким номером нету, то он просто вылетит за край ряда. На каждом из M ходов игрок выбирает одно из двух действий:

  • Установить силу выброса лунки a равной b.
  • Вбросить шарик в лунку a и посчитать количество прыжков шарика, прежде чем он вылетит за край ряда, а так же записать номер лунки, после выпрыгивания из которой шарик вылетел за край.

У Пети есть некоторые проблемы с математикой, поэтому, как Вы уже догадались, именно Вам предстоит произвести все подсчеты.

Входные данные

Первая строка содержит два числа N и M (1 ≤ N ≤ 105, 1 ≤ M ≤ 105) — количество лунок в ряду и количество ходов. Следующая строка содержит N целых положительных чисел, не превышающих N - изначальные силы выброса лунок. Следующие M строк задают ходы, сделанные Петей. Каждая строка может быть двух типов:

  • 0 a b
  • 1 a

Тут, первый тип означает что требуется установить силу выброса лунки a равной b, а второй означает что требуется вбросить мячик в лунку с номером a. Числа a и b - целые положительные и не превышают N.

Выходные данные

Для каждого хода второго типа (задающего вбрасывание шарика) в порядке следования во входном файле выведите два числа через пробел в отдельной строке — номер последней лунки перед вылетом шарика за край и количество прыжков.

Пример 
8 5
1 1 1 1 1 2 8 2
1 1
0 1 3
1 1
0 3 4
1 2

8 7
8 5
7 3
Решение
Задача 13E
Codeforces Beta Round 13 2010.05.06

Задача решается с помощью метода корневой декомпозиции (sqrt-декомпозиции). Идея в том, чтобы разбить лунки на блоки размером примерно √N (≈316) и для каждой лунки предрассчитать:

  1. last[i] — последнюю лунку, с которой мы покинем текущий блок (или саму лунку, если вылетаем сразу)
  2. jumps[i] — количество прыжков внутри блока, прежде чем мы его покинем

Без оптимизации каждый запрос типа 1 мог бы требовать до N шагов (если прыжки маленькие). При N,M ≤ 100000 это дало бы O(N*M) → 10^10 операций — слишком медленно.

С корневой декомпозицией:

  • Каждый запрос типа 1 выполняется за O(√N) шагов, потому что мы перепрыгиваем целые блоки за раз
  • Каждый запрос типа 0 (обновление) требует пересчёта только O(√N) лунок внутри блока

Общая сложность: O((N+M)·√N) → примерно 10^5 * 350 ≈ 3.5×10^7 операций.

#include 

using namespace std;

const int N = 100010;  // Максимальное количество лунок
const int B = 350;     // Размер блока (примерно sqrt(100000)
                       // ≈ 316, взято 350 для запаса)

int n;      // n - количество лунок
int m;      // m - количество запросов
int a[N];            // Сила выброса для каждой лунки
int last[N];         // Последняя лунка в блоке
                     // перед вылетом из блока
int jumps[N];        // Количество прыжков внутри
                     // блока до вылета из блока

// Функция пересчёта параметров для лунки i
void recalc(int i) {
  // Если после прыжка вылетаем за пределы
  // поля ИЛИ перескакиваем в другой блок
  if (i + a[i] >= n || i / B != (i + a[i]) / B) {
    last[i] = i;     // Запоминаем текущую лунку
                     // как последнюю в этом блоке
    jumps[i] = 0;    // Прыжков внутри блока нет
  } else {
    // Иначе прыгаем внутри блока - используем
    // уже вычисленные значения для следующей лунки
    last[i] = last[i + a[i]];
    jumps[i] = jumps[i + a[i]] + 1;
  }
}

int main() {
  ios_base::sync_with_stdio(false);
  cin.tie(nullptr);

  cin >> n >> m;
  for (int i = 0; i < n; ++i) {
    cin >> a[i];
  }

  // Предварительный расчёт для всех лунок (справа налево)
  for (int i = n - 1; i >= 0; --i) {
    recalc(i);
  }

  // Обработка запросов
  while (m--) {
    int type;
    cin >> type;

    if (type == 1) {  // Запрос на симуляцию броска
      int start;
      cin >> start;
      start--;  // переходим к 0-индексации

      int last_lunka = 0;
      int total_jumps = 0;
      int pos = start;

      // Прыгаем блоками до вылета за пределы
      while (pos < n) {
        last_lunka = last[pos];
        total_jumps += jumps[pos] + 1;
        pos = last[pos] + a[last[pos]];
      }

      // Выводим результат (переводим обратно в 1-индексацию)
      cout << last_lunka + 1 << " " << total_jumps << "\n";

    } else {  // Запрос на обновление (type == 0)
      int idx, new_val;
      cin >> idx >> new_val;
      idx--;  // переходим к 0-индексации
      a[idx] = new_val;

      // Пересчитываем только лунки в том же
      // блоке, что и изменённая
      int block = idx / B;
      for (int i = idx; i >= 0 && i / B == block; --i) {
        recalc(i);
      }
    }
  }

  return 0;
}
