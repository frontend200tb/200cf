Треугольное число — это число кружков, которые могут быть расставлены в форме равностороннего треугольника. Например, три кружка можно расставить в форме треугольника, значит три — треугольное число. n-ое треугольное число — это количество кружков в треугольнике, на стороне которого n кружков. Tn = n * (n+1) / 2. Вы можете прочитать подробно про эти числа в Википедии (http://en.wikipedia.org/wiki/Triangular_number или http://ru.wikipedia.org/wiki/Треугольное_число).

Ваша задача — определить, является ли заданное целое число треугольным.

Входные данные

Первая строка содержит одно число n (1 ≤ n ≤ 500) — заданное целое число.

Выходные данные

Если заданное целое число является треугольным, выведите YES, иначе выведите NO.

Примеры

Пример 1

1

YES

Пример 2

2

NO

Пример 3

3

YES
