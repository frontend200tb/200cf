Даны точки на плоскости с целыми координатами: M0, A0, A1, ..., An - 1, где n — нечетное число. Определим бесконечную последовательность точек Mi следующим образом: Mi симметрична Mi - 1 относительно (для любого натурального числа i). Точка B симметрична A относительно M, если M — центр отрезка AB. Для заданного j найдите точку Mj.

Входные данные

В первой строке записано нечетное целое число n (1 ≤ n ≤ 10⁵), и целое число j (1 ≤ j ≤ 10¹⁸) — индекс требуемой точки последовательности. В следующей строке через пробел записаны два целых числа — координаты точки M0. Далее следуют n строк, в i-ой строке через пробел записаны координаты точки Ai - 1. Все координаты не превосходят по модулю 1000.

Выходные данные

Выведите через пробел координаты точки Mj.

Задача о симметричном отображении точки относительно последовательности точек. После n отражений точка возвращается к исходной (если отражать по тем же точкам в том же порядке). Полный период — 2n операций

#include 
#include 

using namespace std;

int main() {
  long long n; // число точек
  long long j; // индекс требуемой точки
  long long x, y; // координаты точки M0
  cin >> n >> j >> x >> y;

  vector A(n+1); // координаты x
  vector B(n+1); // координаты y

  for (int i = 0; i < n; i++) {
    cin >> A[i] >> B[i];
  }

  for (long long d = 0; d < j % (2 * n); d++) {
    x = 2 * A[d % n] - x;
    y = 2 * B[d % n] - y;
  }

  cout << x << ' ' << y;
}
