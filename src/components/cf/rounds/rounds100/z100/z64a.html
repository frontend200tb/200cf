Выведите факториал заданного числа n. Напомним, что факториал числа n равен произведению 1·2·...·n.

Входные данные

В единственной строке входных данных содержится целое число n (1 ≤ n ≤ 10).

Выходные данные

Выведите факториал числа n.

Примеры

Пример 1

3

6

Пример 2

5

120
