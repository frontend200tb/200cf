Вася пришел в магазин cash-n-carry, положил в корзину n товаров и пошел на кассу оплачивать покупку. Каждый товар характеризуется ценой ci и временем ti в секундах, в течение которого кассир пробивает этот товар. За время, пока кассир пробивает товар, Вася может украсть некоторые другие свои покупки из корзины. На то, чтобы своровать один товар, Вася тратит ровно 1 секунду. Какое наименьшее количество денег Васе придется заплатить? Помните, что порядок, в котором кассир будет пробивать товар, определяет Вася.

Входные данные

В первой строке задано число n (1 ≤ n ≤ 2000). В каждой из n следующих строк задано описание одного товара парой чисел ti, ci (0 ≤ ti ≤ 2000, 1 ≤ ci ≤ 10⁹). Если ti равно 0, то у Васи не получится украсть ни одного товара за время, пока кассир обрабатывает товар номер i.

Выходные данные

Выведите одно число — ответ на задачу: какое наименьшее количество денег придется заплатить Васе.

Примеры

Пример 1

4
2 10
0 20
1 5
1 3

8

Пример 2

3
0 1
0 10
0 100

111
Решение
Задача 19B
Codeforces Beta Round 19 2010.06.24

Это классическая задача о рюкзаке с минимальной стоимостью для достижения необходимого «веса» n:

У нас есть n предметов. Каждый предмет i имеет «вес» t_i и «стоимость» c_i. Мы хотим минимизировать стоимость выбранных предметов, но при этом они должны давать сумму t_i такую, что количество невыбранных предметов n - k не превосходит этой суммы.

Динамика: dp[s] — минимальная стоимость выбранных товаров, дающих суммарный вес ровно s (где вес = t_i + 1).

Инициализация: dp[0] = 0, остальные — INF.

Для каждого товара обновляем рюкзак в обратном порядке.

В конце ответ — минимальное dp[s] для всех s >= n.

#include 
#include 

using namespace std;

int main() {
  int n; // число товаров
  cin >> n;

  vector t(n), c(n);
  for (int i = 0; i < n; i++) {
    cin >> t[i] >> c[i];
  }

  const long long INF = 4e18;
  vector dp(n + 1, INF);
  dp[0] = 0;

  for (int i = 0; i < n; i++) {
    int weight = t[i] + 1;
    for (int s = n; s >= 0; s--) {
      if (dp[s] == INF) continue;
      int ns = min(n, s + weight);
      dp[ns] = min(dp[ns], dp[s] + c[i]);
    }
  }

  cout << dp[n];
}
