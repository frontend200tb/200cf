В озере живет n рыб, пронумерованных от 1 до n. Каждый день ровно одна пара рыб встречается друг с другом, причем вероятности встречи каждой пары равны между собой. Если две рыбы с номерами i и j встретились, то первая съест вторую с вероятностью aij, а вторая первую –– с вероятностью aji = 1 - aij. Этот процесс продолжается, пока в озере остается хотя бы две рыбы. Для каждой рыбы посчитайте вероятность того, что она останется последней в озере.

Входные данные

В первой строке содержится целое число n (1 ≤ n ≤ 18) — число рыб в озере. Далее следует n строк по n вещественных чисел — матрица a. aij (0 ≤ aij ≤ 1) — вероятность того, что рыба с номером i съест рыбу с номером j. Гарантируется, что на главной диагонали матрицы стоят нули, а для всех остальных элементов выполняется: aij = 1 - aji. Все вещественные числа даны не более чем с 6 знаками после десятичной точки.

Выходные данные

Выведите n вещественных чисел, разделенных пробелами, с точностью не менее 6 знаков после точки. Число с номером i должно быть равно вероятности того, что рыба с номером i останется последней в озере.

Решение
Задача 16E
Codeforces Beta Round 16 2010.06.03

Ключевая идея решения — динамическое программирование по битовым маскам

1. Состояние — битовая маска

int mask = битовая_маска_живых_рыб

mask — число, где бит i равен 1, если рыба i жива

Всего возможных состояний: 2^n (от 0 до 2^n - 1)

2. Значение состояния — вероятность

dp[mask] = вероятность оказаться в состоянии mask

Изначально: dp[2^n - 1] = 1 (все рыбы живы)

В конце: dp[1 << i] — вероятность того, что осталась только рыба i

3. Переходы между состояниями

Как из состояния mask попасть в другие состояния?

Подсчитываем количество живых рыб: aliveCount = popcount(mask)

Количество пар живых рыб:

totalPairs = C(aliveCount, 2) = aliveCount * (aliveCount - 1) / 2

Для каждой пары (i, j) живых рыб:

  • Вероятность выбрать именно эту пару: 1 / totalPairs
  • Вероятность того, что i съест j (а не наоборот): prob[i][j]
  • Итоговая вероятность перехода: dp[mask] * prob[i][j] / totalPairs
  • Результат: рыба j умирает → новый mask без бита j

Формула перехода:

dp[mask_without_j] += dp[mask] * a[i][j] / (aliveCount * (aliveCount - 1) / 2)

4. Направление обхода

Почему for (mask = all-1; mask >= 0; --mask)?

Это обратный проход — от большего числа рыб к меньшему:

  • Начинаем с mask = все рыбы живы (максимальное число)
  • Переходим к mask'ам с меньшим количеством рыб
  • Каждая новая маска имеет МЕНЬШЕ единичных битов, чем исходная
  • Идем сверху вниз, потому что из состояния с большим числом рыб мы попадаем в состояния с меньшим числом

Время: O(2^n * n^2) — для каждой маски перебираем все пары рыб

Память: O(2^n) — храним массив вероятностей

Для n ≤ 18 это работает быстро (≈ 262144 состояния).

int main() {
  int n;
  std::cin >> n;

  // Используем vector вместо статического массива
  std::vector> prob(n, std::vector(n));

  // Чтение матрицы вероятностей
  for (int i = 0; i < n; ++i) {
    for (int j = 0; j < n; ++j) {
      std::cin >> prob[i][j];
    }
  }

  // Динамическое программирование: dp[mask] - вероятность оказаться в маске
  int totalMasks = 1 << n;
  std::vector dp(totalMasks, 0.0);
  dp[totalMasks - 1] = 1.0;  // Изначально все рыбы живы

  // Обратный проход по маскам
  for (int mask = totalMasks - 1; mask >= 0; --mask) {
    // Подсчет количества живых рыб в текущей маске
    int aliveCount = 0;
    for (int i = 0; i < n; ++i) {
      if (mask >> i & 1) aliveCount++;
    }

    // Если жива 1 или 0 рыб, то переходов нет
    if (aliveCount <= 1) continue;

    // Общее количество пар живых рыб
    int totalPairs = aliveCount * (aliveCount - 1) / 2;

    // Перебираем все пары живых рыб
    for (int i = 0; i < n; ++i) {
      if (!(mask >> i & 1)) continue;  // Рыба i мертва

      for (int j = 0; j < n; ++j) {
        if (i == j) continue;
        if (!(mask >> j & 1)) continue;  // Рыба j мертва

        // Вероятность того, что i съест j
        double eatProb = prob[i][j] / totalPairs;

        // Новая маска, где j умирает
        int newMask = mask ^ (1 << j);
        dp[newMask] += dp[mask] * eatProb;
      }
    }
  }

  // Вывод результатов для каждой рыбы
  std::cout << std::fixed << std::setprecision(6);
  for (int i = 0; i < n; ++i) {
    std::cout << dp[1 << i];
    if (i != n - 1) std::cout << " ";
  }
  std::cout << std::endl;

  return 0;
}
